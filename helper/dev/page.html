                      Snapshots
                      
                
                      • Loading…
                      
                
                      
                  
                      How it works
                      
                  
                        
                    
                      • A snapshot keeps the data in production, the code, the memory of the lead, and the record of the app.
                        • 
                    
                      • hi makes a snapshot each day, before each publish, and before it copies data to production.
                        • 
                    
                      • To go back to a snapshot, an admin runs hi app restore on the machine. hi makes a snapshot of the app as it is now first. You are an admin: open the admin page ↗

                      Data in the preview
                      
                
                      The preview uses a copy of the data in production. What you try there does not change production.
                      
                
                      
                
                      
                  
                
                      
                
                
                      
                  
                      How it works
                      
                  
                        
                    
                      • The preview gets a new copy after each publish.
                        • 
                    
                      • When new work goes on the preview, it gets a new copy if its copy is more than 1 hour old.
                        • 
                    
                      • If the preview has data that production does not have, hi does not replace it. The data stays until someone copies it to production.
