1What it's for

The same data, wherever the work runs.

On a machine connected to your team's hi server, hi data runs the official hf tool, pointed at the server. Nobody needs a Hugging Face account of their own.

Download, and know what you got

In a project, hi records the exact commit it downloaded, so a teammate gets the same files and a result can be traced to its data.

$ hi data get example-org/prices-1d $ hi data get # everything .hi5/data.json records

Read it straight from code

load_dataset, from_pretrained, and hf:// paths work with private repositories, without a download step first.

$ hi data run -- python backtest.py

In a box, or on a rented GPU

Boxes and agents get a placeholder token; rented machines get one that reads only the repositories you named.

$ hi agent claude --data "train the ranker on example-org/prices-1d" $ hi compute run --gpu a10g-small --data example-org/prices-1d train.py
2Try it

Your first download in a minute.

On a machine connected to your team's server, with an organization your admin has added.

  1. Install hf, Hugging Face's own tool.

    $uv tool install huggingface_hub

  2. Join your team's server, if you haven't. An admin approves it.

    $hi connect hi.example.com

  3. Search and pick. Type words in any order; Enter picks one, and hi asks before it downloads.

    $hi data

  4. Or name it, with its size first.

    $hi data info example-org/prices-1d && hi data get example-org/prices-1d
3How it works

A short token from the server, the files from Hugging Face.

hi asks the server for a token that works only against your server, from your machine, for a day. The server swaps in the team's token on the way to Hugging Face.

{% include diagram.html name="data" %}

The server passes on only reads of one repository or bucket: nothing that uploads, deletes, or changes settings. Removing your machine or user ends your token at once.

File contents come straight from Hugging Face's storage, so large downloads don't go through the server. The server records who downloaded what; it never sees the files.

Running hi data get again fetches only what is missing or changed, so an interrupted download continues where it stopped.

4The details

Finding, filtering, recording, and running elsewhere.

What to reach for beyond one download.

Find what you need

$ hi data ls # kind, name, size, update $ hi data ls example-org --kind bucket $ hi data ls --json # for scripts and agents

When a dataset, a model, and a bucket share a name, put dataset:, model:, or bucket: in front.

Part of it, or a version

$ hi data get example-org/ranker --to models/ranker $ hi data get example-org/prices-1d --revision v2 $ hi data get example-org/fdb --include 'runs/2026-09/*'

Datasets and models download with hf download, buckets with hf buckets sync. Buckets have no revisions.

Keep track in a project

In a project made with hi init, hi data get records the repository, the exact commit, the folder, and the filters in .hi5/data.json. Commit it, and hi data get with no name gets a teammate the same files. A branch or tag is pinned to the commit it pointed to; buckets record their file list, and hi warns when one has changed. --no-record skips it.

A shell, a notebook, a box

$ eval "$(hi data env)" # HF_ENDPOINT and HF_TOKEN $ hi data run -- jupyter lab $ hi box run --data -- python train.py

In a box, hi's proxy outside adds the real token on the way to the server and allows Hugging Face's download hosts. An open network and --data don't go together.

On a rented GPU

$ hi compute up --on runpod --gpu rtx-4090 --name train --max 4h --data example-org/prices-1d

Before the machine starts, hi asks the server for a token that reads only the repositories you named, so a refusal costs nothing. It writes the token to ~/.hi/data.env on the machine over SSH, never into the provider's console. Not on RunPod's Community Cloud.

For admins

$ hi server data add example-org # on the server box $ hi server data list

Use a fine-grained, read-only token limited to the organization. Every group reads everything by default; list patterns in policy.json, such as "data": ["example-org/prices-*"], to limit one.
